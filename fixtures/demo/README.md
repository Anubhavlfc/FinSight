# Offline demo fixture: SYNTHETIC DATA

**Nothing in this folder is real financial data.** "DEMO ANALYTICS CORP", "SAMPLE BANK
CORP" and "DEMO ROBOTICS INC" are made-up companies with made-up CIKs (0009999901–03).
Every entity name carries the suffix `(SYNTHETIC FIXTURE)` and each JSON file has a
`_fixture_notice` field, and the CLI prints a banner whenever these files are used.

The files copy the *shape* of three SEC EDGAR endpoints so the full pipeline can run
without network access or API keys:

| File | Mimics |
|---|---|
| `company_tickers.json` | `https://www.sec.gov/files/company_tickers.json` |
| `submissions/CIK##########.json` | `https://data.sec.gov/submissions/CIK##########.json` |
| `companyfacts/CIK##########.json` | `https://data.sec.gov/api/xbrl/companyfacts/CIK##########.json` |

They are generated by `scripts/build_demo_fixture.py`, which documents the traps built
into the data (a restatement, a 10-K/A, a quarterly value labelled as fiscal-year, a
competing tag, duplicate rows, a loss-to-profit transition and negative free cash flow).
`tests/unit/test_pipeline_demo.py` checks the pipeline against values worked out by
hand from that script.

Regenerate with `python scripts/build_demo_fixture.py`.
